## ⚠️ About This Repository

This repository is a **showcase only**. The source code is intentionally not included, and this is a collaborative project that was not built solely by me. Original project maintainer: **Hakan Keser**.

## Overview

WellDone is a web and mobile platform that supports an **EU transnational project** integrating **wheelchair skills training into university curricula**. It promotes inclusive mobility practices, knowledge exchange, and digital dissemination across Europe. It is available as a website and as a mobile app on Google Play.

## Key Features

- **Content Management** – Create, edit, and publish blog posts with rich media support.
- **Video Training** – YouTube playlist integration with automatic synchronization, comments, and ratings.
- **Analytics Dashboard** – Page views, visitor engagement, and country-based statistics.
- **Mobile App** – Cross-platform mobile support with Capacitor, published on Google Play.
- **Admin Panel** – Secure, authenticated interface for managing content and moderation.

## Tech Stack

React 19 · Vite · Capacitor · Node.js / Express · MongoDB / Mongoose · JWT · Docker
